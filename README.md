# CMD Learning Project

A Python project designed for learning command-line interface concepts and property management. It includes modular examples for different properties and settings.

## Features
- Modular property system
- Example demonstrations for each property
- Easy-to-extend structure

## Requirements
- Python 3.x

## How to Use
Run the main script and follow the prompts. Type property names or "Example" to see demonstrations.

```bash
python main.py
```

## Project Structure
- `main.py` - Entry point
- `laws.py` - Core logic
- `settings.py` - Configuration
